`lib/compositions.mjs` 是可编辑且可追踪的原创创作源：音符用 MIDI 音高、起始拍与持续拍明确记录，另列和弦、回答声部及泛音。没有把旧曲谱改名或从旧曲谱取片段。`lib/render.mjs` 只负责确定性合成、留有峰值余量的整体增益、循环接缝与结尾淡出，以及原创 PCM16 WAVE 编码。

音源保留 Shanshui 的 MIT 合成方程（古筝、箫、泛音与混响），许可全文在 `LICENSES.md`。对原音源适配器的变更只增加真正单次播放时不回卷事件与尾音的模式；乐谱与音色算法是不同来源。当前闭包不包含 Liyue、Syrtis、NumPy 或旧库的其他曲谱。

本地试听由本任务编写的 `audition.mjs` 生成，无联网、付费模型或外部采样。WAV 为 48 kHz / PCM16 / 双声道；两段循环首尾差为 0，三段没有非有限样本或削波，峰值约 -8.88、-9.82、-10.28 dBFS。测量与容器检查不等于人工听感验收。

正式游戏仍用 Engine 0.5.0 原生 Pack → cook → DDC → catalog → Host 音频服务。试听 WAV 仅供审听，不用直接文件读取绕过资产身份。三个 package ID、sourceKey 与原三 cue GUID 保持稳定，更新的是对应资产内容。
