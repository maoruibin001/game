# 阴影稳定性与回归

适用于《拍一卷山色》的静态建筑、地形和会动的投影物。用固定构建和同一块地面做对照。整体缓慢位移、轮廓起伏和明暗跳变要分别记录。

## 游戏侧处理

- 第一天从 13:00 开始。前 30 秒有效游玩时间（20 山谷分钟）内，太阳圆盘和实际方向光共用开场方向。稳定窗口在开场时刻前后对称，读档或手动回到同一时刻会得到同一方向。13:20 后连续过渡，13:40 回到日照轨迹。
- 这项调整位于 [原生环境运行时](../assets/environment/runtime.ts)。它只调整渲染的太阳方向和太阳圆盘位置。游戏时钟、天气过渡、光照色调、摄影时段、日出日落和后续天数沿用原规则。无需增加或迁移存档字段。
- 静态构件继续投影，风旗、风车等有实际动作的构件继续由各自的动画更新。不要为了稳定门影暂停世界、停掉动画或关闭整场景的阴影。区分从阴影图读取的假波动和真正的动画投影。
- 已验证的接收端配置保存在 [太阳光组件](../assets/entry/engine.pack.ts)。方向光使用一套随玩家位置覆盖峡谷的世界空间投影和连续的光空间 PCF Soft 核。云雨和低角度日照仍逐渐减弱清晰的投影。

## 复现与归因

| 操作 | 需要记录的输入 | 如何判断 |
| --- | --- | --- |
| 从标题页正常新开一局，走到邮局门楼下。看铺路和草地交界，停住人物和镜头 12 秒。 | 构建、视口、画质、天气、钟表、太阳方向、相机与角色位置。 | 影子整体位移和太阳方向同步，先查游戏光照。修复版开场的时钟仍推进，太阳方向保持一致。 |
| 仍在正常新档中，小幅向右转镜头后转回，角色不移动。 | 连续保留相机姿态与帧，比较相同世界坐标的草地。 | 转镜会让画面像素整体移动。用姿态把帧对齐到同一地面再判断阴影是否在抖。 |
| 诊断时再用游戏里的创作模式固定时刻和天气，先停镜，再重复转镜。 | 确认实际光向、天气与投影物变换均保持固定，记录渲染后端与画质。 | 固定输入仍会随机晃，或静态影子只跟屏幕位置变化，再抓 Engine 帧检查级联和接收采样。固定时刻的通过结果无法覆盖普通开场。 |
| 在固定光照下分别观察山脊的旗帜、已转动的风车以及旁边的静止立柱。 | 同时拍到物体及其影子，确认动画有在运行。 | 影子与物体动作、方向一致属于正常动影。相邻静态物体的阴影应保持稳定。 |
| 放开时钟，观察开场结束后的过渡，随后核对黄昏、夜间和次日。 | 记录光向、天空和太阳圆盘，另外复查相机模式、休息跳时与续档。 | 开场后太阳应逐渐恢复移动，连接处无跳向。晴天的渐变和夜里熄落应保留。 |

## 可重复执行的检查

正常输入和实际截图由 ForgeAX 的硬件浏览器会话产生。第一组停镜和转镜使用正常时钟，按引擎实际报告的时刻取样。后续太阳恢复的专项检查可推进模拟时间，以缩短等待。

```sh
pnpm exec forgeax project play scripts/qa/opening-sun-shadow.mjs \
  --backend hardware --headless false --viewports 1920x1080 --timeout-ms 125000 --json
```

脚本将具名截图和 `acceptance.json` 保存在 `.forgeax/diag/opening-sun-shadow/owner/`。在有 NumPy 与 Pillow 的 Python 环境中，传入本次实际的截图目录。

```sh
python3 scripts/qa/opening-shadow-pixels.py --check <截图目录>
```

像素脚本用相机姿态把截图投回同一块草地，比较 8 位绿色通道平均绝对差。当前 1920×1080 邮局窗口的回归上限为停镜 **0.35**、转镜 **1.0**。脚本会检查取样区域确实覆盖门影。换设备、画幅或受光地形时需重新选同一世界位置的参考区域，不能把这些阈值套到无关镜头。

环境单测覆盖开场光向、实际游戏时钟、雨天、提前或延后设时的衔接、黄昏和次日。视觉验收还应抽查邮局门楼、旧镇石拱、禅院墙边及山脊旗杆的近远阴影和低画质。保留失败截图与读数，避免把只检查单张画面或只调软边当成修复通过。


## 全谷回归

邮局高廊、门楼、林地、旧镇和禅院共用同一条投影更新链。由实际日照方向生成光空间基底，在光线轴上旋转栅格，避免长直檐和台阶同时越过一整列采样点。覆盖窗口按旅人所在的光空间页移动。每页是完整的阴影贴图 texel 数，固定太阳时跨页重叠区保持采样格对齐。转镜、相机拉近和取景变焦不参与投影计算。三档使用不同覆盖和分辨率。全世界地图只渲染玩家附近的投影窗口，远过窗口的模型仍有方向光和天空填充。[投影策略](../assets/environment/valley-shadow.ts)

1. 在同一预览产物、浏览器后端和画质下，从标题点击「背上行囊，出发」。依次实走高廊下山路、邮局门前、松针邮袋旁和风来林地。确认脚位、机位、朝向与候选身份落盘，保持旧包入口作对照。
2. 每处先等跟随相机停稳，再保持角色、镜头不动，用真实时钟录下至少 8 秒。纪录起止时刻和太阳方向。回看日照正常扫过阴影边缘，另外统计同一位置短时反复变亮和变暗的像素比例。
3. 打开摄影日程「自由创作」，在晴朗 14:20 切回世界后等实际方向稳定，再转镜往返、左右各走一步。确认每帧实际光向相同。移动镜头时先将静止受光面投到相同的世界位置，另圈出角色、旗、前景遮挡和地形轮廓供人工检查。
4. 按同样条件比对通过岔口时的浅色路面。道路单测以实际绘制三角形接续和分层计数为准，碰撞查询继续使用相同的步行高度。检查固定时刻还能看到动态投影，恢复旅途后时钟推进，黄昏和夜间光照仍然不同。
5. 跨区域或改阴影实现时，再抽查跨页重叠区、近处脚底接触和远处投影边缘，记录三个画质档。固定相机组可比较原始像素，固定光向的转镜组通过相应表面平面对齐。两组共用亮度反转比例和变化 P95，不能把正常扫过的单向光影运动算作闪动，也不能把丢失投影算作通过。

```sh
pnpm exec forgeax project play --script scripts/qa/global-shadow-regression.mjs \
  --backend hardware --headless false --viewports 1920x1080 --timeout-ms 330000 --json
python3 scripts/qa/global-shadow-pixels.py <录屏目录> --clip '01-邮局门楼-固定' \
  --rect 742 903 1430 1810 --plane y=14
```

录屏和逐帧 PNG 由脚本从实际画布保存。每帧的时刻、相机朝向、光向和画质见同目录 `acceptance.json`。矩形参数为 `Y0 Y1 X0 X1`，需选同一块无遮挡的受光面。离开平坦区域后可给垂直墙面指定 `x=...` 或 `z=...`，曲面应分片并分别记录机位。对照多个构建时，用 `--reference <目录>` 固定所有构建使用的世界采样点。旧局部定点数据保留为历史阳性与阴性样本。

## 邮局门影历史验收

以下读数来自旧版 15:30 开场的同场景前后对照。对比前后各约 12 秒的停镜实际帧，门影草地边缘的平均亮度差从 **2.815** 降到 **0.066**。修复版用运行中的时钟转镜并回转，地面对齐后的平均亮度差为 **0.28–0.53**。稍后时钟推进至约 15:50，太阳方向已经恢复变化。短时运动的测量范围仅限上述邮局视角。 [新档实机记录](../artifacts/play/scripts/qa/opening-sun-shadow/play.json) · [门影前后对照](../.forgeax/diag/opening-sun-shadow/门影前后对照.png) · [修复后像素读数](../.forgeax/diag/opening-sun-shadow/final-pixels.json)


## 13:00 正常入口复验

晴天从标题页开新档，约 13:02 开始取样，人物和镜头静止，再左右转镜并回转。取当前光向下草地右侧的门影。按相机姿态投回相同世界位置后，停镜平均绝对亮度差为 0.052、0.179，转镜与回转为 0.404–0.623，全部在现有门槛内。随后推进模拟时钟，日照恢复转动。此复验只覆盖开场普通入口的这块草面。 [实机数据](../artifacts/render-regression/opening-13-report.json) · [像素结果](../artifacts/render-regression/opening-13-pixels.json)

## 旧镇木桥与上院红柱

遇到已经放平的木桥时，先在同一朝向横移镜头，再固定光向关闭太阳投影重复。此前草绿与木棕会在同一世界点来回切换，关掉投影仍可复现。沿真正的桥跨把草面压低后，主木板 2,288 个采样点均高出地形 0.25 米。几何测试对桥面与实际地形三角形的正面积重叠区域验净空，同时检查桥头行走高度和山脊栈台。正常从标题页进入，在绞盘打开木屏、拍下石拱后双向通过木桥。桥抬起时仍拦路。 [几何回归](../assets/shanye-world/__tests__/exposed-decks.test.ts) · [普通入口脚本](../scripts/qa/render-regression-walk.mjs)

红柱取大殿南廊靠石础的静止漆面，在 15:00 起锁定镜头，依次微调太阳光向。先保留无投影、固定光向两组底噪。旧投影开着时，柱面相邻帧红色通道的单步 P95 最高达 17/255，而首步关闭投影为 0。将光向间隔从 1/12 缩细到 1/90 山谷分钟后，仍有一次跳到 20/255。仅平滑游戏时钟的更新不足以根除这处闪烁。加宽 PCF 5×5 后粗步进峰值降到 11/255，但出现反复变亮、变暗的像素由 2,348 增至 3,118，不能将软边视为通过。相关参数保留原状。

新的场景按用途登记桥跨、栈台、柱脚、屋檐投地影和远景栏杆。每类保留已知故障机位和稳定对照，记录近景接收面在固定光与移动光下的单步变化、反转次数与区域大小。移动镜头的像素需要先对齐世界表面。角色、风吹装饰、雨滴和遮挡边缘另做掩码。可按复现环境逐项检查 CSM 的投影矩阵、光向步进、接收偏移及过滤。 [复用方法](../.agents/skills/voxel-flicker-audit/SKILL.md) · [本项目基准机位](../.agents/skills/voxel-flicker-audit/references/project.md)
