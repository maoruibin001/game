# 摄影委托与走路回归

首轮在旅行册「来信」内显示三个固定题目。给阿禾寄山可寄零峰、一峰或双峰。认路可在林间交一张，或在东岭交红箭头和风车两张。先拍石拱放下桥，再把山门拍进老窗，在客堂交件领金柳。白天先寄自己的明信片也可以，结束页、散场提示、随身地图与客堂会接回未交的老窗。交过老窗后，来信页接下一轮，夜里仍能借火把燃放花盒。

第二轮起，每轮三处地点取不同实景组。用存档种子洗牌，优先抽尚未出现的景点，内室揭晓后加入。所抽地点、已经签收的照片、当前花谱和新一轮在同一存档里保存。合格原片必须在本轮开始后拍摄。同一张不能重复交，一轮只领一次。新旅程从金柳开始补齐十种花盒，花谱齐后仍可交件领取留样以外的普通花盒。老档保留原花谱、跑跳和原故事进度。合格时段针对委托与打卡，其他时候可以自由拍和留存原片。

## 普通入口复验

1. 标题进入新档。拍一个没有装进山的信封，再横移拍双峰。在来信选择零峰实拍并确认仍能寄出。用另一新档确认默认选择双峰，并可手动换选。
2. 分别从走路和相机按 J，明确选东岭或林间，立即看小地图上的名称与亮线，再按 W 确认迈步。再测举机 → M → 景点导航，以及举机 → 摄影日程 → 导航到这里。M 再 M、来信里的临时地图、关闭底片查看都应按打开时的入口返回。停止跟随不退出玩家当前的页面。
3. 13:00 打开摄影日程，选晨间邮局廊前。HUD 显示「次日 06:00–09:00」。刷新继续保持目标和时段；次晨 06:20 显示「06:00–09:00」。可以在 13:00 去那里拍自由照。
4. 试 0、1、8、9、12 张精选。0–8 张只显示第一页，9–12 张可翻到下一页。资料缩减至八张时自动回到第一页。底片上限八张，精选上限十二张。
5. 用两种合法顺序核对「先寄自己的明信片」和「先交老窗」。先寄时，按「再走一会儿」后看散场短句、HUD、随身地图、客堂是否指向同一件未完的事。交过老窗后核对来信里的新一轮与夜间放花。
6. 记录第二轮实际抽到的地点，拿一处做同地背对主体、只拍半组（适用双主体时）、再换站位拍清主体的对照，保留原片。交齐三张，领盒并重载，确认第三轮和库存不变。

批量数学回归和存档 fixtures 使用 `pnpm exec vitest run`。`scripts/qa/commission-rounds.mjs` 用正常键鼠、快门和页面按钮跑实景流程。坐标是行走与构图目标，脚本不修改角色位置、抽签种子或任务状态。
