# 《拍一卷山色》夜晚与烟花结局验收

供第三批开发与独立验收使用。最近核对的候选为 2509fd4，开发交付范围为邮局开场。本文记录烟花的目标体验与取证办法。时长和分镜为首轮建议，最终以普通玩家能看清、来得及构图、愿意留下照片为准。

## 夜晚的两条入口

- 13:00 开始旅行，17:30 预告晚钟，18:20 日落，18:40 闭院。熟路玩家白天可以办完任务并持有烟花。已在山上的人停在原位，可摸黑下山；山路无固定照明，夜里看不清山景，走偏可能跌落。普通玩家不可从山脚夜间上行；持烟花的人可领火把上山。
- 花街夜市白天市门关闭、摊棚收起；鱼灯、夜信等夜市互动随开市启用。普通镇街与白天任务保留各自入口。18:40 开市后所有玩家均可入内，06:20 收摊；验收包含未接任务、没有烟花和火把的新档。首夜回镇就看得见鱼灯游过门洞。随手可摇灯合影；愿意细看可凭信封上的缺月找到修灯人，送达后两道鱼影在墙上相会。想继续白天行程，可以在客栈登记或凭木牌入住至次晨 06:20。白天的照片和已交件进度连续。
- 已取得烟花，奖励由玩家留在背包里。小镇全域禁止布置和燃放烟花，镇外空地或半山松台可亲自布置并点火。也可委托阿禾在镇外代放，自己从街边或客廊取景。人在次日、细雨或已完成其他支线，仍可用这份奖励。实际日夜按世界时钟推进。

## 这场烟花要让玩家看到什么

白天在老窗边看过山口，晚上玩家有机会用自己选的构图，把同一处山口拍成最后一张。在旧街拍镇外烟花时，近景有屋脊和灯笼；镇外晒谷场能见双峰与天空，客廊可借窗棂做前景。优先在一处机位做出可以交稿的成片，再看其他站位的取舍。

建议以约 35–45 秒试排三段。首束单独升起，短暂停在安静的夜色里，交代主花会在哪片天，留给玩家举机、横移和变焦的时间。中段让暖金的主花越过屋脊，在山口上方展开；亮起时屋檐或窗格短暂受光，镇内取景时摊灯仍然可辨。收束时余光缓慢下垂，最后留一小段安静。若白天确已见过阿公的窗，可让那盏暖灯向山下轻轻回应两次，普通机位看不清的细节不写成玩家已经看到的事。此为分镜建议，开发可交付效果更好的同等安排。

玩家自行决定开始时刻，镜头和快门全程可用；原片保存的是自己按下的那一帧。可不拍、可补拍，跨过晨钟或重载时有一致的收场或再赏入口。细雨夜仍有可辨轮廓，避免全屏白闪和骤然过响。阿公窗台的第二张底片属于后续加分项，基础结局和手拍原片须先成立。

## 交给验收的证据

1. 一条普通键鼠、含现场声音的连续录屏，从携带烟花、选机位、发信号，到拍照、选片和相册导出。另给首夜没拿到烟花的短路线，核对能玩、能借宿、次日能续办。
2. 交三张真实 1920×1080 JPEG，分别为旧街屋脊、镇外晒谷场双峰和客廊窗景，三张的燃放地点均在镇外；至少一张按自然雨夜或薄雾拍。第一轮可先给最好的一个机位，最终再补齐。附一张由其中原片导出的明信片。检查 240px 小图里还能认出山谷，原图高光里看得到烟花形状。
3. 同一设备和画质记录燃放前、主花展开时的帧耗时 P95、拍照响应和实际保存结果。核对错过主花、重看、跨晨钟、奖励未使用就重载。烟花已经播放与玩家已经拍好满意的照片分别记录。
4. 两位初见玩家自己选什么时候开始、在哪拍，看是否都能正常完成，再请各自挑一张愿意留下的照片，说出取舍。若想保留的是角色、屋脊、山与烟花之间的关系，说明这个结尾用到了整趟摄影旅行。由真人分别听近街和远窗的环境底声、烟花和尾音，记录实际感受。

## 新增验收场景：提灯上山，亲手布置烟花

本人已明确游戏内的操作顺序为“从行囊取烟花 → 放到地面 → 用火把点火”。以下为纳入第三批的夜行与交互建议。此前的“自行开始”按这条正常操作路径验收。阿禾代放仍可用于远处取景。

- **夜行资格。** 18:40 后，普通登山路封闭，禅院停止交件。持有烟花的人可在山脚或松台山亭领取火把。山脚查验所持烟花和火把后开放夜行邮路；已在路上的人可以下行。无火把时山路没有固定照明或发光路标。摆下烟花、举机或燃放结束后，玩家可以在开放区域换位和返程。初版先核一个低处开阔场地和一个山上场地。
- **火把的照明。** 玩家能看清自己的落脚点、下一个转弯和回程方向。首轮试以脚边约 0–4 米清楚、向外至约 10–12 米逐渐衰减，仅被火把照到的路面或路桩获得局部亮度。具体数值以晴夜和细雨实机为准。按正常跑速也应提前认出岔口，远山仍维持夜色。举机时火把垂到画框外，手边留光。首轮不设燃料消耗和雨中随机熄灭。
- **轻量行囊。** 烟花可“取出布置”，火把可“拿起照路”，木牌可在客栈“借宿”。相机继续用既有快捷键，跑跳沿用角色本领。现版“收拾行囊”是设置页，若新入口叫“行囊”，旧入口应明确标为“设置”。同一物品的就地提示和行囊按钮走同一套操作。点选烟花后可挪动地面预览，确认放下，火把仍可直接使用。摆错可收回重摆。
- **放在哪里与从哪里拍是两个决定。** 在镇外晒谷场或半山松台的开阔地内，玩家能自行选落点；从地面预览就能辨别坡边和遮挡。在烟花旁，手持火把可执行“点燃烟花”。首束是可辨的开场，主花前留普通玩家后撤、举机的余量。远机位可由玩家先布置、再到老窗等合法观景点举灯示意，由阿禾使用火把代点。亲手点火始终是完整的默认路径。
- **交验。** 普通键鼠连续录一次从镇口领火把、寻路上山、选地放下、收回换位、持火把点燃、转身举机到导出原片。用同机位记录持灯与收灯，实走转弯、雨夜、下山。跨镇界检查镇内无法布置、无法点燃，镇内逛市或观赏可正常进行。分别在未摆放、已摆未点、表演结束三个状态重载，核对物品和场上烟花相符、返程通畅、补拍可用。未领奖的新档仍能完整游玩鱼灯与住宿。第一份山上原片应能同时辨出烟花和山谷中的前景。

### 末钟响起时，玩家已经在山上

17:30 第一声晚钟预告收件截止，18:20 日落逐渐转暗，18:40 末钟关普通上行和收件窗口，镇内花街开市。人在原处，走路和已开始的拍摄继续。无火把下山只能摸黑辨认脚下，不能借沿途照明拍清山景，也可能失足跌下山。关闸时正在过门或身处远端支路的人可从内侧退出；院内客廊和出院侧门留用，已完成的交件及烟花保留。若玩家已经领到烟花，在松台山亭就可借火把，直接布置，无需下山往返。

普通输入分别从山脊取景、坡路中段、院门门槛三处跨过末钟。核对位置与镜头连续，每处确有可步行的下行路径但无公共照明。用同机位对比无火把和持火把的可见范围；测试走偏发生真实跌落、跌落后的恢复与照片保留，以及读档后能继续下山。天黑本身不触发复位。
