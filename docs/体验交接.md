## 阴影专项

**P2 · 固定建筑投影像波浪。** 从新档走到邮局门楼下，朝铺路和草地交界的门影看，分别停着观察十余秒、小幅拖镜头、切换阴天和细雨。上一轮消除了随屏幕采样旋转的主要波动。本轮在固定时刻对照了转镜头，在普通时钟下对照了太阳移动，确认原本笔直的投影边缘还会因为阴影图采样出现起伏。

当前共用的太阳光提高了近处阴影的采样精度，使用固定的光照空间采样和更宽的近远阴影过渡。投影强度会随云雨与太阳高度变淡。晴天的影子会随日照方向缓慢平移，风车叶片、旗帜等实际运动仍可产生动态投影。

邮局专项用正常键鼠进入，对照同一片门影边缘。普通时钟下，边缘相对直线的起伏从平均约 1.57 像素降到 0.83 像素。固定时刻、静止镜头的对应像素无变化，小幅转镜仍比上一版稳定。阴天和细雨已有实际帧。风车、石拱和山脊观景站另做了固定视角和小幅转镜的画面对照。这个数据对应 1920×1080 的邮局视角，不代表所有设备和地点。后续体验优先在旧镇石拱、禅院墙边、山脊逆光和低画质各选一处，用同样手法复验。 [专项走查记录](../artifacts/play/scripts/qa/shadow-stability/play.json) · [同一门影的晴天前后、阴天与细雨](../.forgeax/diag/shadow-stability/clear-and-weather.jpg)

开场普通时钟的光源运动已补做游戏侧稳定处理，复现、归因、动影和日夜回归见 [阴影稳定性与回归](阴影稳定性.md)。

| P1 | 从邮局走到林地、旧镇，停留听一轮，再刷新接着玩。将配乐调低，靠近和远离风铃与风车。 | 前三处共享约 54.55 秒循环，重进从头开始。风、雨、鸟鸣、风铃、风车声已存在，仍缺少区域差异和具体物体的方向感。 [音频体验评估](音频体验评估.md) |

| P2 | 旧镇绞盘打开后，在石拱外拍红邮筒、石拱、双峰，缩为约 240 像素宽。 | 合格照片里双峰容易输给色彩更强的屋顶。让没读过构图说明的人先指出最抢眼的三件东西。 |
